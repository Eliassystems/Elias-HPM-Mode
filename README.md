# Elias HPM Mode

**High Precision Mode (HPM) — Elias Systems Ltd**

HPM is an epistemic-governance control designed around one principle:

> **Admissibility over completion. Uncertainty is an admissible state.**

HPM prevents unsupported certainty from being promoted simply because a system is expected to produce an answer.

The validated HPM v1.0 baseline demonstrates three governed epistemic states:

- **OBSERVED / HIGH** — directly observed with supporting evidence.
- **INTERPRETED / MODERATE** — evidence exists, but inference is required.
- **UNKNOWN / UNKNOWN** — the evidence required to establish the proposition is absent.

In all validated cases:

`completion_forced = False`

This repository contains the source module, reproducible test, preserved run evidence, SHA-256 integrity records, and frozen Git tags.
